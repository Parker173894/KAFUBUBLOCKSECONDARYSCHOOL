KAFUBU BLOCK SCHOOL PORTAL - VERSION 21
PUPIL REGISTRATION INTERNAL SERVER ERROR FIX

UPLOAD ONLY THESE TWO FILES

FILE 1: app.py
GitHub location: repository root

1. Open the Kafubublock GitHub repository.
2. Open app.py.
3. Click the pencil/Edit button.
4. Select all the old code and delete it.
5. Open the new app.py from this package, copy all its code and paste it into GitHub.
6. Click Commit changes.

FILE 2: students.html
GitHub location: templates/students.html

1. Return to the repository root.
2. Open templates.
3. Open students.html.
4. Click the pencil/Edit button.
5. Replace all the old code with the code from templates/students.html in this package.
6. Click Commit changes.

DEPLOY ON RENDER

1. Open the Render service.
2. Wait for automatic deployment or choose Manual Deploy, then Deploy latest commit.
3. Wait until the service shows Live.
4. Refresh the Pupil Register page with Ctrl + F5.

WHAT THE FIX DOES

- Stops duplicate pupil numbers from causing an Internal Server Error.
- Shows which pupil is already using the number.
- Prevents accidental double registration.
- Saves the pupil and pupil login together.
- Shows a clear retry message when the database is temporarily busy.
- Automatically uses the assigned class-teacher name when the Class Teacher field is blank.

IMPORTANT

- Every pupil must have a different Pupil Number.
- Do not upload or replace school.db.
- Do not delete the Render persistent disk or /var/data.
